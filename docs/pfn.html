Phonetic Feature Notation

Phonetic Feature Notation (PFN) is a language-independent phonetic notation.

Isochronic Chunk

While “chunk” is roughly equivalent in meaning to “syllable” it is also possible for a chunk to consist solely of consonants or to be silent.

A Isochronic Chunk consists of tokens separated by spaces.

The first token specifies the natural language characters corresponding to the chunk. Use a space if none is required.

Next, specify the duration of the chunk. For example, to set it to 80% of the default length, specify =0.8. If omitted, the default length will be used.

If an entire chunk is silent, place a period.

e.g. A Japanese word “イッパン”, means “General” or “Common”, consistes 4 molas. ッ is no audible release and ン is solely of nasal consonant.

イ =0.8 fv %7 ! | %5 p0 | 10 A %7 A8
ッ =0.8 f0Lv0c 40 v0 20 %7 ! | %5 p6
パ f5Lv0c 40 v0 20 f5o9v %7 ! | %5 p6
ン =0.8 Fnv 60 %7 ! | %5 p6 | %7 A8
 .

Time and Dulation

Time is expressed as a relative value within a chunk. In the initial state, the current position points to the start of the chunk. The length of a chunk varies depending on the speech speed.

PatternExample
\d+10Move 10 ms forward from the current position (with a time resolution of 2.7 ms)
\$$Beginning point of syllable ending
\||Return to the start of the chunk
%\d%3Move to the 30% position of the entire chunk
%\d\d%45Move to the 45% position of the entire chunk

e.g. pan (Monosyllabic word)

f5Lv0c 40 v0 20 f5o9v %7 ! $ Fnv 70

The onset is f5Lv0c 40 v0 20, the nucleus is f5o9v %7 !, and the coda is $ Fnv 70.

The onset has a duration of 60 ms, the coda 70 ms, and the remainder constitutes the nucleus.

If the nucleus is shorter than 20 ms, the durations of the onset and coda consonants are reduced to compensate; however, a lower limit is set for the total duration of the syllable to ensure that the duration of any consonant does not fall below half of its original value.

Where the term "specify the ratio" appears in the following, it shall be interpreted as referring to one of the three methods of specification described below.

Parameter Interpolation

Values ​​between two points for which parameters have been specified are determined via linear interpolation. For positions before the first specified point or after the last specified point, the value of the nearest specified point is used.

However, if there is a silent interval (A0) between points, no interpolation is performed.

e.g. Pitch curve

%3 P4800 %7 P5000

Tones

Absolute Specification

Specify the value in cents following P. The neutral value is 4800. (One octave is 1200 cents, and a semitone in 12-tone equal temperament is 100 cents.)

Relative Specification

Specify the ratio following p. The actual pitch is specified via other parameters.

e.g. The third tone of Mandarin “mǎ” is written as f5Lnv 20 ! 40 f5o9v | %2 p3 %5 p0 %8 p (Tones are %2 p3 %5 p0 %8 p)

Amplitude

Specify the ratio following A. The amplitude is proportional to the square of the value.

The voicelessness is specified the ratio following v, and the glottal stopness is specified the ratio following g.

Vowel Height and Backness

The front-to-back position (the most back = 0) is specified the ratio following f. The height (the narrowest = 0) is specified the ratio following o.

e.g. Close front vowel [i] is written as fo0v, but o0 is often omitted, and they are written simply as fv.

Place of Articulation

The dorsal consonants is speficied the ratio following f (Velar = f0, Palatal = f). The laminal consonant is speficied the ratio following F (Palatal = F0, Alveolar = F).

e.g. Palatal approximant [jä] is written as fv 70 f5o9v (The consonant is fv 70)

Section of Articulation

Section of Articulation is specified by e and f/F.

If e is not specified, it is assigned the same value as f/F.

e.g. Palatalized Velar stop [ɡʲi] is written as f0ecv 20 fv, but f0 is often omitted, and they are written simply as ecv 20 fv.

Labial Roundness

Specify the ratio following L.

Degree of Retroflex

Specify the ratio following r.

Lateralness

Specify the ratio following a.

Degree of Sibilant

Specify the ratio following s.

Nasalness

Specify the ratio following n.

n0 is oral sound, n is nasal consonant. When a vowel is produced with n5, it becomes a nasal vowel.

Degree of Occlusion

Specify the ratio following c.

When denoted as c0, there is no closure. when denoted as c, there is a complete closure at the point of articulation.

Keeping c5 produces a fricative sound.

When transitioning from a closed state to a degree of occlusion of 95% or less, a plosive sound corresponding to the place of articulation is produced. Releasing a closure with a lip-rounding degree of 85% or greater results in the production of a bilabial plosive.

Parameter Hysteresis

  • L : Labial Roundness
  • r : Degree of Retroflex
  • a : Lateralness
  • s : Degree of Sibilant
  • n : Nasalness
  • c : Degree of Occlusion

If any of the above parameters are specified, the unspecified parameters will retain the values from the previous specification.

If F/f/e/o is specified, the following applies:

  • If any of F/f/e/o is specified, the other parameters (L/r/a/s/n/c) are reset to 0.
  • If only F/f is specified, e is set to the same as F/f and o is set to 0.
  • If only e is specified, f/o is set to 0.
  • If only o is specified, f/e is set to 0.

Re-designation

! is for a given point in time, re-specify the parameters that were set immediately prior—excluding tone p/P and volume A.

e.g.

f5o9v %8 !

It is equivalent to the following code.

f5o9v %8 f5o9v
