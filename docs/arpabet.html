ARPABET

ARPABET is a set of phonetic transcription codes. It represents phonemes of English (GA) with ASCII characters.

Examples

IPAARPABET
Hello[hɛlˈoʊ]HEH LOW1
Speech[spˈiːtʃ]SPIY1CH
