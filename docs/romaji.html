表音式ローマ字

表音式ローマ字 (ひょうおんしきろーまじ、英:Phonetic Romanization)は、日本語の音声・アクセントをASCIIで記述するための表記法である。

ヘボン式ローマ字との差異

  • 鼻濁音はg~と表記する。
  • 声門閉鎖音はqと表記する。
  • 長音は母音を重ねて表記し、「エイ」「オウ」は、ee / ooと表記する。
  • 1拍開ける場合はスペースを置く。ピリオドやカンマは置かない。
  • アクセントにより相対的にピッチが高くなる拍は大文字にする。

五十音表

異音の条件は以下の通り。母音の無声化はア行に示すが、他の無声子音の列も同じ。

  • #_ : 語頭
  • _# : 語末
  • V_ : 直前が母音
  • C̥_ : 直前が無声音
  • _C̥ : 直後が無声音

声門閉鎖音

声門閉鎖音・声門破裂音はqと表記する。

アッ
表記aq
音価[äʔ]

促音

促音は直後の子音を繰り返す。ただし、以下の場合は異なる字を置く。

  • 破擦音は内破音(破裂音)に置き換える。例:「マッチ」MAtchi
  • 歯茎硬口蓋音は歯茎音に置き換える。例:「キャッシュ」KYAsshu
  • 促音に母音が続く場合や、促音で終わる場合は声門閉鎖音を置く。
  • 歌唱においては曲に合わせて長音に置き換える場合がある。

撥音

撥音はnと表記する。(唇音が続く場合でもmは非推奨)

直後にヤ行または母音が続く場合は、拗音またはナ行と区別するためアポストロフィーで区切る。例:「しんよう」shiN'YOO

異音は以下の通り。

nCンンカンタンパンヤ
表記nnkantanpan'ya
音価[ɴ][ŋkä][ntä][mpä][ɲjä]
nVンアンインウンエンオ
表記n'an'in'un'en'o
音価[ãä][ĩi][ɯ̜̃ɯ̹][ẽ̞e̞][õ̞o̞]

長音

長音は直前の母音を繰り返す。3拍以上の場合も拍数に応じて繰り返す。

例:「経営」keEEE

アクセント

アクセントにより相対的にピッチが高くなる拍は大文字にする。

例:「琵琶湖」BIwako / biWAko
