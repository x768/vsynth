NinbosVoice (Artifical Voice)

NinbosVoiceは、JavaScriptで実装した音声合成ソフトウェアです。以下のリンクからブラウザ上で実行できます。

NinbosVoice Speech Synthesizer

特徴

  • 肉声不使用のロボットボイス
  • 100%ルールベースなので棒読み
  • 非ユーザーフレンドリー、記法覚えてね
